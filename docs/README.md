[PRJ-0376] 어도비 커머스(Adobe Commerce) 마켓플레이스 확장 연간 구독 판매

Adobe Commerce(옛 Magento) 쇼핑몰 운영자가 설치하는 확장(예: 주문 정리, 재고 알림, AI 상품 설명 초안)을 만들어 마켓플레이스에서 연 구독으로 판매. 근거: Adobe 개발자 문서에 확장을 자동 갱신 연간 구독으로 판매할 수 있다고 안내됨(수수료율과 정산 조건은 확인 못함, 실제 수익은 추정 불가). 무자본 이유: 개발은 무료 도구로 가능하나 판매자 등록비와 한국 정산 가능 여부는 확인 필요(불가하면 제외 검토). 기존 PRJ-0115(WordPress 플러그인)·PRJ-0114(Shopify 앱)와 다른 플랫폼. 주의: 고객 주문·결제 정보 처리 방침 명시, 자동 결제 조작 금지. 출처: https://developer.adobe.com/commerce/marketplace/guides/sellers/subscriptions/selling-subscriptions

설계 문서·자료를 이 폴더에 넣습니다.
